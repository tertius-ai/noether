# Security policy

Please do not open a public issue for a suspected security vulnerability.
Report it through
[GitHub private vulnerability reporting](https://github.com/tertius-ai/noether/security/advisories/new)
or email `contact@tertius.cc`. Include the affected revision, a minimal
reproduction, and the impact when possible.

The current `main` branch and latest tagged source release receive security
fixes. Older source tags may be used to reproduce results but are not maintained
as supported release lines.

Ordinary correctness bugs, unsupported mathematical inputs, and performance
regressions can be reported through the public issue tracker unless disclosure
would expose a security weakness.
